# Titanic Survival Prediction

Machine Learning project to predict passenger survival on the Titanic dataset.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Project Steps
1. Data cleaning and preprocessing
2. Exploratory Data Analysis (EDA)
3. Feature engineering
4. Logistic Regression
5. Model evaluation (Precision, Recall, ROC-AUC)

## Results
The model predicts passenger survival and highlights the most important factors such as sex, age, and passenger class.
